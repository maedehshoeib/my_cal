# 🧮 سیستم محاسبه مالیات علی‌الحساب

سیستم هوشمند محاسبه مالیات علی‌الحساب با در نظر گرفتن ضریب وفاداری مالیاتی

## 📋 ویژگی‌ها

- ✅ محاسبه مالیات بر اساس **رگرسیون خطی**
- ✅ پیش‌بینی سود سال جاری با استفاده از داده‌های 3 سال گذشته
- ✅ تعدیل اتوماتیک با **ضریب تبدیل** (شاخص تولیدکننده بانک مرکزی)
- ✅ محاسبه **ضریب وفاداری** بر اساس 5 دسته عملکرد مالیاتی
- ✅ اعمال تخفیف بر اساس رفتار مالیاتی مودی
- ✅ محاسبه موازی برای **ابرازی** و **قطعی**
- ✅ ذخیره و مدیریت رکوردهای متعدد
- ✅ خروجی Excel/CSV

## 🎯 فرمول‌های استفاده شده

تمام فرمول‌ها بر اساس فایل اکسل رسمی سازمان امور مالیاتی پیاده‌سازی شده‌اند:

### 1. تعدیل با ضریب تبدیل
```
مقدار تعدیلی = مقدار × (1 + ضریب تبدیل)
```

### 2. رگرسیون خطی
```
y = bx + y₀

b = [(مقدار₂ - مقدار₁) + (مقدار₃ - مقدار₂)] ÷ 2
y₀ = مقدار₁ - b
پیش‌بینی سال 4 = 4b + y₀
```

### 3. محاسبه مالیات
```
مالیات اولیه = سود × 0.25
درصد تخفیف = (نمره کل ÷ 25) × حداکثر تخفیف
مالیات نهایی = مالیات اولیه × (1 - تخفیف ÷ 100)
```

## 🚀 راه‌اندازی پروژه

### پیش‌نیازها
- Node.js (نسخه 14 یا بالاتر)
- Python 3.8 یا بالاتر
- npm یا yarn

### نصب و اجرا

#### 1. کلون کردن پروژه
```bash
git clone <repository-url>
cd my_cal
```

#### 2. نصب وابستگی‌های فرانت‌اند
```bash
cd frontend
npm install
```

#### 3. نصب وابستگی‌های بک‌اند (اختیاری)
```bash
cd ..
pip install -r requirements.txt
```

#### 4. اجرای پروژه

##### روش 1: فقط فرانت‌اند (توصیه می‌شود)
```bash
cd frontend
npm start
```

برنامه در `http://localhost:3000` اجرا می‌شود.

##### روش 2: با Docker
```bash
docker-compose up
```

## 💡 نحوه استفاده

### 1. وارد کردن اطلاعات هویتی
- نام و نام خانوادگی
- شماره اقتصادی
- کد ملی

### 2. وارد کردن اطلاعات مالی 3 سال گذشته
برای هر سال:
- فروش (ابرازی و قطعی)
- درآمد (ابرازی و قطعی)  
- سود (ابرازی و قطعی)
- **ضریب تبدیل** (مثلاً 0.15، 0.20، 0.22)

### 3. ثبت عملکرد مالیاتی 5 سال گذشته
چک کردن موارد زیر برای هر سال:
- ✅ تشکیل پرونده مالیاتی
- ✅ تسلیم اظهارنامه
- ✅ پرداخت سرموعد
- ✅ الزامات کارپوشه
- ✅ صورتحساب الکترونیکی

### 4. تعیین حداکثر تخفیف
پیش‌فرض: **50%** (قابل تغییر)

### 5. محاسبه و مشاهده نتایج
- مشاهده اطلاعات تعدیل شده
- مشاهده ضرایب رگرسیون
- مشاهده پیش‌بینی سال جاری
- مشاهده مالیات اولیه و نهایی
- ذخیره رکورد
